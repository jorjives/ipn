# For engineers

IPN is the language. `ipngine` is a Python 3.12 reference engine with no
dependencies. These pages are how to run it, embed it, and extend it.

The [command line](cli.md) is the supported interface: `check`, `quote` and
`batch`. [Embedding the engine](embedding.md) is the same calls from Python.
The [grammar](reference/grammar.md) is the syntax for another implementation.
[Contributing](contributing.md) is how the reference engine grows.
