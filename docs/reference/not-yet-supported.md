# Not yet supported

A policy carrying amounts in two currencies at once (a limit in USD on a premium in GBP),
more than one product per file, new-for-old versus indemnity as a named
settlement basis (use a depreciation table), a display label beside a choice's code (use
the code, or the label, as the value). Each is a small addition to the engine; say
which you need.
