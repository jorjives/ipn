# Not yet supported

Gaps in the **language** (no construct yet): a policy carrying amounts in two
currencies at once (a limit in USD on a premium in GBP); more than one product
per file; new-for-old versus indemnity as a named settlement basis (use a
depreciation table); a display label beside a choice's code (use the code, or
the label, as the value).

The **host platform** owns documents, schedules, certificates and notices;
the underwriter's handling of a referral; billing and collections beyond the
instalment schedule the file describes; audit evidence and data provenance;
reinsurance; production controls. The language can `refer` a risk; it does not
run the referral.

**Conformance** today is the examples' scenarios and this reference. There is
no separate conformance suite.

Say which gap you need.
